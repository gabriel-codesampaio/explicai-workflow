# Interface

- Todo controle tem nome acessível; ícone sozinho tem `aria-label`.
- Funciona inteiro pelo teclado, com foco visível e ordem lógica.
- Contraste de texto de pelo menos 4,5:1, nos dois temas.
- Cor nunca é a única forma de passar informação (status, erro).
- Estados: carregando, vazio, erro e sucesso existem e dizem o que fazer.
- Texto da interface no tom do projeto: frase curta, o botão diz o que acontece, o erro diz como resolver. Sem tom de IA.
- Texto novo passa pela tradução, se o projeto tiver mais de um idioma.
- Larguras estreitas e largas não quebram nem transbordam.

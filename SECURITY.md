# Segurança

Este plugin só tem texto (agentes e skills em Markdown) e um script de validação. Mesmo assim, agentes têm acesso a Bash e a arquivos do seu projeto: leia o que instala.

Achou uma falha ou um agente que vaze segredo? Escreva para gabriel@codesampa.io, sem abrir issue pública.

# Security

This plugin is plain text (Markdown agents and skills) plus a validation script. Agents still get Bash and file access in your project, so read what you install.

Found a vulnerability, or an agent that leaks secrets? Email gabriel@codesampa.io instead of opening a public issue.
